                    DIPLOMACY PERSONA STRATEGY GUIDE

CORE PHILOSOPHIES (Early → Mid → Late Game)

┌─────────────────────────────────────────────────────────────────────────────┐
│ APEX PREDATOR 🦁                                                            │
│ Philosophy: Board Analysis + Coalition Mechanics                           │
├─────────────────────────────────────────────────────────────────────────────┤
│ Early:   Grab Centerlands + Southvale (empty SCs first)                     │
│ Mid:     Identify leader → Form coalition against them                      │
│ Late:    Break treaties at optimal moment → Push to 5 SCs                   │
│ Key:     Adaptable to any board state, responds faster than others          │
│ Win:     Via timing and ruthless coalition play                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ ART OF WAR ⚔️                                                                │
│ Philosophy: Deception, Speed, Terrain Control (Sun Tzu)                    │
├─────────────────────────────────────────────────────────────────────────────┤
│ Early:   SPY heavily to understand all rivals' true strength                │
│ Mid:     Build overwhelming SUPPORT chains (unstoppable formations)         │
│ Late:    Execute swift, devastating strike on isolated weak rival           │
│ Key:     "Appear weak when strong" (misdirection in communications)         │
│ Win:     Via speed, deception, and control of hub territories (5+ connects) │
│ Unique:  Measures "formation strength" via SUPPORT chains, not just SCs     │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ GAME THEORIST 📊                                                            │
│ Philosophy: Nash Equilibrium, Prisoner's Dilemma, Expected Value           │
├─────────────────────────────────────────────────────────────────────────────┤
│ Early:   Map territory values (hubs = 5x periphery value)                   │
│ Mid:     Form mathematically optimal coalition (Shapley value)              │
│ Late:    Betray only when expected value calculation says so (rational)     │
│ Key:     "Silent unless message changes payoff matrix" (less communication) │
│ Win:     Via optimal coalition selection and rational betrayal timing       │
│ Unique:  Calculates cost/reward for every move, picks best expected value   │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ SCORPION 🦂                                                                  │
│ Philosophy: Patience, Endgame Dominance                                     │
├─────────────────────────────────────────────────────────────────────────────┤
│ Early:   Claim empty SCs, avoid early conflict                              │
│ Mid:     Consolidate, let others exhaust each other                         │
│ Late:    Identify strongest survivor → Build coalition to eliminate         │
│ Key:     "Win through attrition, not aggression"                            │
│ Win:     Via endgame coalition when all others are weakened                  │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ MACHIAVELLI 😈                                                               │
│ Philosophy: Betrayal as Theater, Deceptive Alliances                        │
├─────────────────────────────────────────────────────────────────────────────┤
│ Early:   Forge truces liberally (appear trustworthy)                        │
│ Mid:     Build false complacency in allies                                  │
│ Late:    Betrayal with theatrical flair (unexpected, memorable)             │
│ Key:     "Trust is currency; spend it when it matters"                      │
│ Win:     Via surprise betrayal at critical moment                           │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ AGGRESSIVE ⚔️                                                                │
│ Philosophy: Blunt Offense, Constant Pressure                                │
├─────────────────────────────────────────────────────────────────────────────┤
│ Early:   Attack contested SCs immediately (even risky)                      │
│ Mid:     Pressure all neighbors simultaneously                              │
│ Late:    Overwhelm the weakest remaining rival                              │
│ Key:     "Offense is the best defense; constant threat"                     │
│ Win:     Via fast early SC accumulation (or by crushing others)             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ CAUTIOUS 🛡️                                                                  │
│ Philosophy: Defense, Stable Alliances                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│ Early:   Build defensive pacts, avoid SC loss at all costs                  │
│ Mid:     Consolidate holdings via SUPPORT chains                            │
│ Late:    Participate in stable coalition, outlast others                    │
│ Key:     "Never lose what you have; slow growth is fine"                    │
│ Win:     Via grinding the game to stalemate or outlasting                   │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ DEFAULT 📋                                                                   │
│ Philosophy: Balanced Offense/Defense                                        │
├─────────────────────────────────────────────────────────────────────────────┤
│ Early:   Grab empty SCs, propose light pacts                                │
│ Mid:     Balanced mix of offense and defense                                │
│ Late:    Adapt to whoever is winning                                        │
│ Key:     "No big risks, no big rewards; reliable baseline"                  │
│ Win:     Rarely; serves as baseline for testing others                      │
└─────────────────────────────────────────────────────────────────────────────┘

WHEN TO USE EACH PERSONA
================================================================================

WANT TO WIN GAMES?
  → Use: Apex Predator (most adaptable, highest win rate)

WANT PURE STRATEGY/DECEPTION?
  → Use: Art of War (Sun Tzu's philosophy, speed + deception)

WANT MATHEMATICAL ELEGANCE?
  → Use: Game Theorist (Nash Equilibrium, expected value)

WANT ENDGAME DOMINANCE?
  → Use: Scorpion (thrives when all others are exhausted)

WANT UNPREDICTABILITY?
  → Use: Machiavelli (betrayal is always an option)

WANT TO TEST OTHERS?
  → Use: Default or Cautious (simple baselines for comparison)

WANT CHAOS?
  → Use: Aggressive (creates constant pressure, forces reactions)
